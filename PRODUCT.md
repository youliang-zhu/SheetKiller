# Product

## Register

product

## Users

SheetKiller is for job applicants who repeatedly fill online application forms across Chinese and international recruiting systems. They are usually in a focused, high-stakes workflow: keep their personal profile accurate, scan a live application page, let the extension fill what it can, then review everything before submitting manually.

## Product Purpose

SheetKiller reduces repetitive application-form data entry while keeping the user in control. Success means the product can reliably identify fillable fields, map them to local profile data, explain what it is doing, never perform final submission, and leave a useful debug trail when a real-world form behaves unexpectedly.

## Brand Personality

Calm, capable, slightly playful.

## Anti-references

Avoid marketing-style landing-page UI, oversized decorative cards, vague AI magic copy, hidden long-running states, and mixing unrelated configuration with profile editing. The product should not feel like a black box that silently waits or guesses.

## Design Principles

1. Keep profile data and system configuration separate.
2. Show the current automation stage so the user knows what is happening.
3. Prefer clear task progress over decorative motion.
4. Treat AI as an assistant with reviewable output, not as an authority.
5. Keep final submission and ambiguous decisions under user control.

## Accessibility & Inclusion

Use readable contrast, visible focus states, concise Chinese-first labels, and reduced-motion-friendly state transitions. Status feedback should not depend on color alone; text labels should state the current stage and outcome.
